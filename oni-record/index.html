Oni Record · Oni생기부

Student records, written and checked in one table

Korean teachers write a short, rule-bound comment for every student in every subject, then check each one against the official writing guidelines before entering it in NEIS, the national school information system. Oni Record keeps that whole job in a single spreadsheet-like window on the teacher's own PC.

Workspace

One window, three areas

The layout follows a spreadsheet, because that is where most teachers already draft their records. Sheets run along the top, students run down the grid, and the sidebar changes with the task.

  1. 1Sheet tabs. One sheet per class and record type. The colored badge shows the type at a glance; tabs can be dragged to reorder.
  2. 2Toolbar. Undo, rows and columns, find and replace, import, CSV export, and separate controls for grid text size and whole-window zoom.
  3. 3Grid. Students in rows. The teacher's notes sit in the middle columns and the finished record lands in the last one, with its NEIS byte count underneath.
  4. 4Sidebar. Three modes: 작성 (Write), 점검 (Check) and 도우미 (Assist). It can be hidden to give the grid the full width.
  5. 5Record type. 세특 subject comments, 행특 behavior notes, 자율 autonomous activities, and 기타 for club and career activities. Switching type keeps the table and changes only the sidebar and prompt.
Workflow

From a blank sheet to NEIS in four steps

Each step is a sidebar mode or a single dialog. Nothing is hidden behind a wizard, and every step can be redone for one student without touching the rest.

1Write

A sheet starts blank, from an Excel, CSV or Google Sheets file, or from records already in NEIS. The columns between the name and the record are the teacher's notes for each lesson or trait.

  • Notes columns and the sidebar list stay in sync. Add, rename or remove an item in either place.
  • Set a target length, tick the students, and generate. AI drafts only for students who have notes.
  • The prompt is editable and saved per record type. Length and activity names are filled in automatically and cannot be deleted by mistake.
  • 매칭 (Match) pulls notes from a file in a different layout, matching by grade, class, number and name with a preview before anything is applied.

2Assist

Finding the right word for each student is the slow part. Assist mode offers keyword chips for the selected cell, so the teacher picks observations instead of typing them.

  • Click a chip and that keyword goes into the active cell. Click again and it comes out. A keyword is never entered twice.
  • The small arrow opens more specific keywords directly under the chip. Both levels can be chosen on their own.
  • Keyword sets follow the record type: five areas for behavior notes, ten subject groups for subject comments, and separate sets for autonomous, club and career activities.
  • Search filters every level at once. 모두 접기 closes all open branches.

3Check

Checking happens on a copy. Oni Record makes a separate check sheet, so the original text is never overwritten until the teacher decides.

  • Before and after sit side by side, with the changed words highlighted and the reason given in plain language.
  • Each student is marked fixed, unchanged or needs review. If the AI shortens a record too much, the original is kept and flagged instead.
  • Accepted corrections are applied back to the original sheet in one action.
  • 교차점검 (Cross-check) opens a second window for checking records exported from elsewhere, such as a colleague's Excel file.

4Apply to NEIS

Approved text goes into the NEIS grid through the Oni browser extension. The app matches each record to a student by class, number and name, fills the grid, saves once, then reads the saved result back to confirm it matches.

The grid

It behaves like the spreadsheet teachers already know

No new habits to learn. The shortcuts, selection and clipboard match what a teacher expects from Google Sheets or Excel.

TypingStart typing on any cell, including Korean input. Enter or F2 edits, Enter confirms and moves down, Tab moves right, Esc cancels, Alt+Enter adds a line break.
Copy and pasteCtrl+C, X, V work across ranges and exchange cleanly with Google Sheets and Excel.
Undo and findCtrl+Z and Ctrl+Y for every edit, including AI drafts and keyword chips. Ctrl+F finds and Ctrl+H replaces.
Byte counterNEIS limits records by bytes, not characters, and a Korean character counts as three. Long-text cells show their byte count so a record is never rejected at the last step.
Columns and rowsText, long text, number and tag columns. Drag to resize columns and rows; a column never shrinks below its header.
Import and exportExcel, CSV and Google Sheets in, including files with several tabs. CSV out, encoded so Excel opens Korean text correctly.
Reading comfortGrid text size and window zoom are adjusted separately. Light and dark themes follow the system or can be set by hand.
Data · reviewed 2026-10-09

What stays on the PC and what leaves it

Student records are sensitive, so the app is explicit about where they go. Compare storage and transfer across Oni apps.

Stored locally

Writing sheets, student cell contents, generated text, preferences and prompt templates are saved in store.json in the Windows user profile. The separate check window uses store-check.json. The reviewed app source does not sync these sheets to an Oni account cloud. These work files are not encrypted by the app.

The teacher's own AI key

Drafting and checking use Google Gemini with the teacher's own API key. The desktop app protects the saved key using Electron safeStorage (Windows DPAPI); this does not encrypt the work sheets. Requests go directly from the desktop app to Google's API.

What is sent to the AI

Generation and checking send task prompts and the selected work content to Google Gemini. Local file storage does not mean that AI processing stays offline. Review the content before requesting an AI operation.

NEIS only on request

Nothing is entered in NEIS until the teacher opens the apply dialog and confirms. The extension works only on the NEIS tab already open in the browser.
