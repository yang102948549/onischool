# ONI Class standalone product page

English product guide with six screenshots rendered from the original ONI Class components and CSS using fictional classroom data. Application UI is Korean.

Open index.html directly or serve this directory with a static server. No build is required. This page is intentionally separate from the existing home page and oni-class route; integration is deferred.

Screens cover the calendar, student profiles, attendance, submissions, lesson progress and widget gallery. Screens can be enlarged. The guide distinguishes local records from mobile sync data.

Verified at 1440, 390 and 320 pixel viewport widths: image loading, horizontal overflow, internal links, image dialog open/Escape and FAQ interaction. Submission checkbox changes were exercised in an isolated in-memory application preview. Native Windows operations, live cloud synchronization and NEIS transfers were not verified.

Screenshot capture scripts and compiled application code are not included in this website directory. No real student data is included.
