# Oni School website

Static HTML product directory and product tours for https://onischool.net.

- `index.html`: ecosystem hub. Hero, app directory (every app with status and a link to its tour), what the apps share, about and contact.
- `oni-class/`, `oni-record/`, `oni-proctor/`: app detail pages. All three are generated by `build_pages.py` from one template, so they share the same structure: hero, numbered chapters with enlargeable screens, "before you start", data, getting started with FAQ, closing.
- `build_pages.py`: the generator. Edit page content there and run `python build_pages.py`; do not edit the three `index.html` files by hand.
- `assets/app.css`, `assets/app.js`: shared theme and screen viewer for the app pages, taken from the Oni Class standalone page. Each page sets its accent with a body class (`app-class`, `app-record`, `app-proctor`).
- `assets/class/`, `assets/record/`, `assets/proctor/`: screenshots. Class: rendered from the app components with fictional data. Record: cropped from the Figma sales detail page, pseudonyms. Proctor: captured from the app UI running its built-in sample exam, fictional names.
- `assets/site.css`, `assets/class-tour.css`, `assets/site.js`: home page and 404 styles and the copy-email button.
- `_redirects`: sends the former `/oni-class-detail/` address to `/oni-class/`.
