Features

교사의 반복 업무를 연결합니다.

01

일정과 할 일

학교 일정과 개인 할 일을 달력에서 함께 확인합니다. 날짜를 선택하면 하루 상세 패널이 열리고, 할 일은 체크로 완료할 수 있습니다.

02

명단과 상담 기록

학생 정보를 표에서 수정하고, 학생별 상담·관찰 내용을 정리합니다. 자세한 학생 정보는 PC에 남깁니다.

03

출결 기록과 집계

학생과 출결 칩을 선택해 기록하고 날짜별·학생별로 확인합니다. 나이스 반영은 별도 확인 흐름을 거칩니다.

04

제출·명단 관리

가정통신문, 신청서와 활동 명단을 학생별로 체크합니다. 제출 여부나 선택 항목을 표에서 확인합니다.

05

시간표와 수업 진도

컴시간에서 날짜가 속한 주의 시간표를 불러오고, 수업 진도는 별도로 기록합니다. 조회할 수 없는 주는 앱에서 안내합니다.

06

바탕화면 위젯

달력과 오늘 수업 등 필요한 정보를 바탕화면에서 확인합니다. 전체 앱을 열지 않고도 하루의 흐름을 살펴봅니다.

A day with Oni Class

아침 확인부터, 하루의 마무리까지.

  1. 학교와 학급 준비

    계정에 로그인하고 학교·학급을 설정합니다. 학생 명단과 일정을 가져와 작업 공간을 준비합니다.

  2. 하루 동안 바로 기록

    달력에서 일정을 확인하고 출결과 제출 여부를 정리합니다. 상세 학생 기록은 PC에서 관리합니다.

  3. 확인하고 반영

    출결 내용을 검토한 뒤 지원하는 나이스 화면에 반영합니다. 다른 PC로 옮길 자료는 앱의 백업 기능으로 보관합니다.

나이스 연결 범위
Chrome·Edge 확장과 같은 PC의 연결 프로그램을 사용합니다. 검토한 베타 안내의 지원 도메인은 충북 cbe.neis.go.kr이며, 학교 내부망에서 사용하는 흐름입니다. 다른 교육청이나 외부·EVPN 환경까지 지원한다고 안내하지 않습니다.
Storage & sync

PC에 남는 기록과, 기기를 잇는 기록.

Oni Class는 로컬 저장소와 계정 클라우드를 함께 사용합니다. 모든 자료가 클라우드에 올라가는 것도, 모든 자료가 PC에만 남는 것도 아닙니다.

PC에 보관하는 상세 기록

학생 상세 정보·학적, 상담·관찰 기록, 좌석 배치, 메모, 수업 진도, 설정과 가져오기 이력은 현재 동기화 대상에서 제외됩니다.

계정으로 동기화하는 자료

현재 소스의 동기화 대상은 일정·할 일, 출결, 제출·명단, 시간표와 선택 학급의 최소 학생 명단입니다. 최소 명단은 학생 ID·이름·번호 및 학년도·학년·반을 포함합니다.

로컬 기록 본문 암호화

Windows의 SQLite 저장소에 기록과 백업을 보관하며, 기록 본문에 Windows DPAPI 암호화를 적용합니다. 다른 PC로 옮길 때는 앱의 백업·가져오기 기능을 사용하세요.

나이스 전송은 별도 흐름

교사가 요청한 출결 작업을 브라우저 확장과 로컬 연결 프로그램이 처리합니다. 나이스에 저장된 내용은 앱의 로컬 기록과 구분됩니다.

Before you begin

설치 전에 확인해 주세요.

휴대폰에서도 사용할 수 있나요?

같은 계정으로 연결하는 모바일 웹 화면이 있습니다. PC의 전체 기능을 그대로 제공하는 방식은 아니며, 현재 소스에서는 일정·출결·제출·명단과 시간표를 위한 모바일 기능을 제공합니다. 학생 상세 정보 수정은 PC에서 합니다.

AI API 키가 필요한가요?

Oni Class의 일정·명단·출결 관리 흐름에는 개인 AI API 키가 필요하지 않습니다. 개인 Gemini API 키를 사용하는 학생부 작성·점검 기능은 별도 앱인 Oni Record에서 제공합니다.

나이스 확장은 어떻게 연결하나요?

앱의 나이스 연결 안내에 따라 확장을 설치하고 연결합니다. 검토한 베타 안내는 웹스토어 승인 전 직접 설치 경로를 설명합니다. 학교에서 확장이나 로컬 연결을 차단하는 경우에는 사용할 수 없습니다.

업데이트와 백업은 어디서 하나요?

설정 → 앱 업데이트에서 새 버전을 확인합니다. 중요한 작업을 저장하고 진행 중인 나이스 반영을 마친 뒤 업데이트하세요. 학생 상세 기록을 다른 PC로 옮길 때는 앱의 백업 기능을 사용합니다.
