NEIS support
The connection uses a Chrome or Edge extension and a companion program on the same PC. The reviewed beta guidance supports Chungbuk’s cbe.neis.go.kr on the school’s internal network. Other education-office domains and external or EVPN access are not verified support environments.
Storage & sync

Detailed records stay local. Selected records connect your devices.

Oni Class combines a local store with account-based cloud sync. The following distinction matters when choosing where to keep student information.

Detailed records on the PC

Detailed student profiles, enrollment history, counseling and observation notes, seating plans, memos, teaching progress, settings and import history are excluded from the current sync flow.

Selected records in account sync

The current source syncs events and to-dos, attendance, submissions, timetables and the selected class’s minimal roster. The roster includes student IDs, names and numbers, plus school year, grade and class.

Encrypted local record payloads

The Windows app keeps records and backups in SQLite and protects record payloads with Windows DPAPI. Use the app’s backup and import tools to move records between PCs.

NEIS is a separate transfer

The browser extension and local companion handle the attendance operation requested by the teacher. Records saved in NEIS are separate from the app’s local records.

Before you begin

A few things to know.

Can I use it on my phone?

A mobile web interface connects to the same account. It covers selected workflows rather than the full desktop workspace. The current source includes mobile features for calendars, attendance, submissions and timetables. Detailed student profiles are edited on the PC.

Do I need an AI API key?

The Oni Class calendar, roster and attendance workflows do not require a personal AI API key. AI-assisted student-record drafting and checking are offered in the separate Oni Record app, using the teacher’s own Gemini key.

How do I connect the NEIS extension?

Follow the app’s NEIS connection instructions to install and connect the extension. The reviewed beta guide describes manual installation pending Web Store approval. Schools that block extensions or local browser connections may prevent this feature from working.

Where are updates and backups?

Open Settings → App update to check for a new version. Save your work and finish any NEIS transfer before updating. Use the app’s backup feature when moving detailed student records to another PC.
