Data, app by app

What stays on the PC. What leaves it.

Storage differs across the apps. Local files, account sync, AI requests and NEIS transfers are separate parts of the picture.

App Stored on the PC Sent outside the PC
Oni ClassLocal storage + account sync Detailed student profiles, enrollment history, counseling and observation notes, seating plans, memos, teaching progress, settings and import history. Synced records also have local copies.Record payloads in the Windows SQLite store are encrypted with DPAPI. The current source syncs calendar entries and to-dos, attendance, submissions, timetables and a minimal roster for the selected class to the account cloud. That roster contains student IDs, names and numbers, plus school year, grade and class.Attendance is sent to NEIS when the teacher requests it. Sync availability can differ by release and account status.
Oni RecordLocal files + AI requests Writing sheets, cell contents, generated text, preferences and prompts are saved as local JSON. The separate check window has its own JSON file. The API key is encrypted when OS encryption is available.The current implementation falls back to plaintext key storage if OS encryption is unavailable. Work JSON files are not encrypted by the app. AI generation and checking send prompts and selected work content directly to Google Gemini using the teacher’s API key. Reading or applying NEIS records is a separate user-requested action.The reviewed source does not sync work sheets to an Oni account cloud.
