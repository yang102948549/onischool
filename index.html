프로그램 PC에 저장하는 내용 외부로 전송하는 내용
Oni Class로컬 + 계정 동기화 학생 상세 정보, 학적, 상담·관찰 기록, 좌석 배치, 메모, 수업 진도, 앱 설정 및 가져오기 이력. 동기화 자료의 로컬 사본도 보관합니다.Windows SQLite 저장소의 기록 본문은 DPAPI로 암호화합니다. 현재 소스 기준으로 일정·할 일, 출결, 제출·명단, 시간표 및 선택 학급의 최소 학생 명단을 계정 클라우드에 동기화합니다. 최소 명단에는 학생 ID·이름·번호와 학년도·학년·반이 포함됩니다.나이스 출결은 사용자가 반영을 요청할 때 전송합니다. 배포 버전과 계정 이용 상태에 따라 동기화 범위가 달라질 수 있습니다.
Oni Record로컬 파일 + AI 요청 작성 시트·학생별 셀 내용·생성 결과·화면 설정·프롬프트는 로컬 JSON 파일에, 교차점검 창 자료는 별도 JSON 파일에 저장합니다. 개인 API 키는 OS 암호화를 사용할 수 있으면 암호화해 저장합니다.현재 구현에는 암호화를 사용할 수 없을 때 키를 평문으로 저장하는 예외가 있습니다. 작업 JSON 파일도 앱에서 암호화하지 않습니다. AI 생성·점검 시 프롬프트와 선택한 작업의 내용이 개인 API 키를 통해 Google Gemini API로 전송됩니다. 사용자 요청으로 나이스 기록을 읽거나 반영합니다.현재 검토한 소스에는 작업 시트의 계정 클라우드 동기화가 없습니다.

About Oni School

학교의 반복 업무에서 시작했습니다.

Oni School은 교사가 학교 현장에서 겪는 반복 업무를 줄이기 위해 만드는 교육 도구 프로젝트입니다. 운영·개발은 Oniaby가 맡고 있습니다.

일정과 출결을 챙기는 일, 학생의 성장을 기록하는 일, 시험 감독을 배정하는 일을 각각의 앱으로 정리합니다. 현재 제공하는 기능과 앞으로 만들 기능을 구분해 안내합니다.
