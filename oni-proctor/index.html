Before you start

It runs on one PC, without the internet

The assignment engine is built into the app

  • Setting up, assigning, adjusting, saving and exporting all work offline. Nothing else needs to be installed.
  • The internet is used only when you choose to import a teacher list or timetable from a Google Sheets link or from Comcigan’s public timetable data.
  • Exam and teacher data is kept on the PC. The app has no account and no cloud sync.

What you prepare

Exam dates and periods, the subjects for each grade, the rooms, and the teacher list with subjects and homerooms.

What the app does not guess

A homeroom, role or blocked class that is missing from your source is not filled in for you. The result is only as complete as the conditions you enter.

Flow

The basic workflow

The left menu follows the order of the job: exam setup, teachers, the assignment table, then records.

  1. 1Exam setupRooms by grade, exam days, subjects per period, proctoring mode
  2. 2TeachersImport the list, then set conditions and unavailable periods
  3. 3Auto assignRules first, then an even spread of duties
  4. 4Review and exportCheck warnings, swap by hand, save as Excel
  • Input is saved automatically a moment after you type, and Ctrl+S saves at once. The top bar shows the save status.
  • Changing the schedule or a teacher’s conditions does not wipe an assignment. It is marked as needing re-validation, and only seats that are no longer allowed are cleared.
  • Each exam is kept as its own record, so last term’s exam can be reopened or used as a starting point.

Setup

Exam setup, step by step

The schedule decides which seats exist. A seat is a place a proctor is needed: a room in a period, or a corridor zone.

일정·고사실 · Schedule and rooms

시험 설정
  1. 1
    Register rooms by gradeAdd classes one at a time or several at once, then corridor zones and special rooms.
  2. 2
    Add exam days and periodsEach day is a card with its own number of periods.
  3. 3
    Type the subject into each cellArrow keys move between cells and Enter moves down, like a spreadsheet.
  4. 4
    Split a cell when classes differOpen the picker to add a second subject and choose which rooms each one applies to. Nothing changes until you confirm.

How seats are made. A corridor seat is created only in periods that have an exam. If every subject in a period is self-study, no corridor seat is made.

감독 방식·배정 기준 · Mode and scoring

시험 설정
  1. 1
    Choose the proctoring modeRegular mode places one proctor per room plus corridor duty. 정/부감독 mode places a chief and an assistant, with rooms you mark as single-proctor.
  2. 2
    Set the weightsBy default a classroom duty counts 2 points and a corridor duty 1. Any value of zero or more, including decimals, can be used.
  3. 3
    Set reference countsLimits such as classroom duties over the whole exam or corridor duties in a day raise a warning when exceeded.

Good to know. Reference counts are warnings, not limits: they never block an assignment. In chief and assistant mode every duty counts as 1 point.

Teachers

Teachers and their conditions

Three tabs: the list itself, special teachers who proctor only in set periods, and the periods regular teachers cannot cover.

교사 명단 · Teacher list

교사 설정
  1. 1
    Bring in the listType it, paste a table, open an Excel, CSV or TSV file, use a Google Sheets link, or search a school in Comcigan’s public data. A preview shows how columns were matched and which rows have problems.
  2. 2
    Click a chip to set conditionsSubjects (more than one allowed), one homeroom class, and any classes the teacher must not proctor.
  3. 3
    Set the roleMost are regular teachers. Roles such as roaming or corridor-only change where that teacher may be placed.

Why it matters. A teacher is never placed in their own homeroom, in a blocked class, or in a period when their own subject is being examined. Those rules come from this table.

특별교사 감독 설정 · Special teachers

교사 설정
  1. 1
    Tick the periods they proctorPart-time lecturers, non-subject, roaming and corridor-only teachers are placed only in the periods you tick, and are always used in those periods when possible.
  2. 2
    Choose where they sitClassroom and corridor, or corridor only. A “corridor first” teacher can still cover a classroom when proctors run short.
  3. 3
    Or load from the timetablePeriods can be filled in from an imported timetable instead of ticking by hand.

감독불가 교사 설정 · Unavailable periods

교사 설정
  1. 1
    Leave it empty by defaultRegular teachers are available in every period unless you say otherwise.
  2. 2
    Tick only what is not possibleA business trip or childcare hours, for example, with the reason written beside it.
Assign

Automatic assignment: rules first, then fairness

One button works out the whole roster. Hard rules are never relaxed to fill a seat or to improve a score, and the same rules apply when you edit by hand.

1Rules that never bend

No excluded teachers, no unavailable periods, no own homeroom or blocked class, no period with the teacher’s own subject, one seat per teacher per period, one teacher per seat.

2Priorities, in order

  1. Place special teachers in the periods set for them
  2. Fill as many seats as possible
  3. Respect seat preferences
  4. Narrow the gap between the highest and lowest score
  5. Bring everyone closer to the average

3About ten seconds

The solver works for roughly ten seconds and returns the best roster it found. It states whether that roster was proven optimal or not. You can cancel, and the previous result is kept.

4Checked a second time

A separate checker validates every result. The summary shows seats filled, unassigned seats, count warnings and unmet placements, so nothing is hidden behind a “done” message.

A teacher’s score in regular mode is classroom duties × the classroom weight plus corridor duties × the corridor weight. “Optimal” refers to the conditions you entered: it does not mean that a condition missing from the input was taken into account.

Adjust

Review, then adjust by hand

Real schools have exceptions. Manual changes are held as a draft until you apply them, and the rules are checked on every move.

  1. 1ReviewScores, empty seats and warnings, by teacher or by room
  2. 2Swap or moveClick two cells in the same period, or pick a teacher for a seat
  3. 3Apply changesValidated and saved; until then you can undo or cancel
  • A swap or assignment that would break a rule is refused, and the reason is shown.
  • Changes stay in a draft state across pages until you apply them. Undo and cancel work on the draft.
  • Empty teacher cells can receive a duty, so a seat can be moved as well as swapped.
  • After a manual change, the earlier “proven optimal” label is no longer shown.
Export

Print-ready Excel, and files you can move

  • Daily rosters are laid out to print on A4 landscape. Pick which exam days to include.
  • Choose a roster by teacher, by room, or both side by side on one sheet.
  • A full table can be added, with each teacher’s total duties and score.
  • The whole exam can be exported as a JSON file to back it up or move it to another PC. An imported exam is added as a new record and never overwrites an existing one.
Checklist

Check these before you use it

  • It is an installed Windows program.
  • Assignment, adjustment, saving and export work offline. Importing from Google Sheets or Comcigan needs the internet.
  • Review the imported list before assigning: homerooms, roles and class links that the source did not contain must be completed by hand.
  • Read the warnings and unassigned seats after every run. A finished run can still leave a seat empty when no teacher is allowed to take it.
  • Automatic saving protects against a crash, not against a lost PC. Keep a JSON export as a backup.
Data

What stays on the PC and what leaves it

Based on the app’s documentation and source as of October 2026.

Stored locally

Each exam is saved as a file in the Windows user profile, separate from the program folder, together with the last good copy. A damaged file is reopened from that copy and the app says so.

No account, no cloud sync

The app does not upload teacher or exam data. Syncing to a cloud is outside its scope.

Online only when you import

Fetching a Google Sheets link or Comcigan’s public timetable data is a request you start. It does not sign in to an account or keep syncing afterwards.

Calculated on the PC

The assignment engine runs inside the app. The roster is not sent to a server to be solved.
